# 如何向本资料库提问

把资料库当作 **RAG 知识源**：先检索，再让大模型只基于检索结果作答。

## 推荐流程

1. 用 `multifactor_kb search` 或 `ask` 取出 5–10 个相关块。
2. 把块原文 + 你的问题交给大模型。
3. 要求：**只依据给定资料**；不确定就说不确定；并引用 `source` / 论文名。

## Prompt 模板

```
你是美股多因子研究助手。只能根据【资料】回答，不要编造论文结论。
若资料不足，明确说「资料库未覆盖」。

【资料】
{检索到的 chunks}

【问题】
{用户问题}

请用中文简明回答，并在文末列出引用的 source id。
```

## 好问题示例

- 「Fama–French 五因子相对三因子多了什么？HML 为何可能冗余？」
- 「毛利率（GP/A）为什么比净利率更能预测收益？」
- 「价值与动量为什么负相关？组合有什么好处？」
- 「BAB 的经济逻辑是什么？和低波动因子有何异同？」
- 「q-factor 与 FF5 的盈利/投资定义有何差别？」

## 坏问题示例

- 「明天买什么股票」（本库是学术/方法论，不是荐股）
- 「把 XX 盗版电子书全文总结」（本库不收录盗版书）
