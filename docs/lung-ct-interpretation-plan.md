# 非增强胸部 CT：病灶鉴别（结节 vs 肺炎）模型对比方案

> **你的真实问题：** 片子上某个信号/灶，更像**结节**还是**肺炎（实变/感染）**？  
> **影像：** 非增强胸部 CT  
> **Sybil：** 与这个问题无关，见下文说明后从主测名单移除。

---

## 1. Sybil 到底是什么（以及为什么不适合你）

**Sybil 回答的问题是：**

> 「这份 **低剂量筛查 CT（LDCT）** 的人，在未来 1–6 年里，得肺癌的**风险有多高**？」

| 维度 | Sybil 实际含义 |
|------|----------------|
| 输入 | 整份体积 LDCT（不需要你圈病灶，也不要临床表格） |
| 输出 | 未来肺癌发生的**概率/风险曲线**（文献中 1 年 AUC 约 0.86–0.94） |
| 训练目标 | 预后/筛查风险分层（NLST 等队列里「后来有没有得癌」） |
| 不是什么 | **不是**「这个白影是结节还是肺炎」的分类器 |
| 也不是 | 「当前这灶是不是癌」的诊断器 |

所以：你要鉴别的是**当前这个灶的形态学类别（结节 vs 肺炎）**；Sybil 给的是**整个人未来得癌的风险**。两者问题空间不同，拿来对比没有意义。  
文献：Mikhael et al., *J Clin Oncol* 2023, PMID 36634294。

**本方案结论：非增强、病灶鉴别 → 不用 Sybil。**

---

## 2. 你的任务该用什么模型比

目标改成：对**同一处感兴趣区（ROI）**，比较模型更倾向「结节」还是「肺炎/实变」。

| 角色 | 模型 | 怎么用 |
|------|------|--------|
| **主测** | **CT-CLIP** | 对整卷做多异常 zero-shot；重点看与 `nodule` / `consolidation` / `pneumonia` 等相关标签的相似度或概率，谁更高 |
| **主测（可读解释）** | **CT-CHAT** | 固定提问：该灶更像结节还是感染性实变？依据是什么？ |
| **质控（非诊断）** | **TotalSegmentator** | 确认肺部分割、侧别/肺叶定位，避免喂错方向或截断 |

学术锚点：CT-CLIP/CT-CHAT 基于 CT-RATE（约 2.5 万例**非增强** 3D 胸部 CT + 报告），与你的非增强设定匹配（*Nat Biomed Eng* 2026, PMID 41680439）。

> 说明：公开文献里很少有「结节 vs 肺炎」二分类、且权重开源、又在非增强胸部 CT 上大规模外验的单一专用模型。更扎实的做法是用 **CT-CLIP 的标签竞争** + **CT-CHAT 的形态学陈述**，再由你用放射学标准裁定。

## 3. 对比实验怎么做（针对「一个信号」）

### 3.1 你先定金标准（建议盲法）

在看模型前，用你自己的读片标准先写一句，例如：

- 更像结节：圆形/类圆形、边界相对清、沿支气管血管束或胸膜下、无/少空气支气管征  
- 更像肺炎/实变：片状、符合叶段、空气支气管征、周围树芽/GGO、临床感染背景等  
- 或：不确定 / 需要随访或薄层重建

### 3.2 固定提问（CT-CHAT，保证可比）

只问这一组，不要边看边改 prompt：

1. 请描述双肺主要局灶性异常（位置、形态、密度、边界、内部结构）。  
2. 针对【你指定的位置，如：右下叶背段胸膜下】这一处信号，更支持 **肺结节** 还是 **感染性实变/肺炎**？给出倾向与把握（高/中/低）。  
3. 列出支持结节的影像征象 vs 支持肺炎的影像征象（各 2–4 条）。  
4. 有哪些鉴别诊断需要保留（机化性肺炎、局灶纤维灶、不典型感染等）？

### 3.3 CT-CLIP 怎么读结果

关注标签竞争，而不是只看「有没有异常」：

```
P(结节相关标签)  vs  P(实变/肺炎相关标签)
```

记录：

| 项目 | 记录 |
|------|------|
| 结节侧最高分标签 + 分数 | |
| 肺炎/实变侧最高分标签 + 分数 | |
| 两者差值 / 比值 | |
| 与你金标准是否一致 | 一致 / 相反 / 两者都低（模型没抓住） |

### 3.4 单例判定规则（自测用）

- **一致：** CLIP 标签竞争方向 = CHAT 文字倾向 = 你的金标准  
- **模型内冲突：** CLIP 偏结节、CHAT 偏肺炎（或相反）→ 记「不稳定」，以你读片为准  
- **都低分/含糊：** 该开源通读模型对这灶形态不敏感，换薄层/换窗或仅作阴性参考

## 5. 预期边界（医生自测仍建议心里有数）

- 这是 **n=1 方法试跑**，不能当模型优劣的正式结论  
- CT-CHAT 可能编造征象：必须以原图核对「空气支气管征、边界」等是否真存在  
- 「肺炎」在报告标签里常被拆成 consolidation / opacity / infection 等，CLIP 要比的是**语义簇**，不是某一个英文词  
- 机化性肺炎、圆形肺炎、不典型腺瘤样增生等本身就会让「结节 vs 肺炎」边界变糊——模型含糊有时是问题难，不一定是模型坏
