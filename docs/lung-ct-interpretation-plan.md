# 医生自测：肺部 CT 诊断模型对比实验方案

> **场景：** 医生用自己的肺部 CT，对学术开源模型做诊断能力对比测试（非临床部署、非患者诊疗）。  
> **目标：** 同一份影像、同一套金标准（你自己的读片结论），横向比较模型输出。

---

## 1. 一句话推荐

做「诊断对比」时，不要混比不同任务的模型。按任务分三组，组内对比：

| 对比组 | 比什么 | 推荐参赛模型 | 你的金标准 |
|--------|--------|--------------|------------|
| **A. 通读/多异常** | 能否说出主要阳性发现 | **CT-CLIP**（标签）+ **CT-CHAT**（自然语言） | 你写的简短读片结论 |
| **B. 肺癌风险**（仅 LDCT） | 风险分层是否合理 | **Sybil** | 你对风险/随访建议的判断 |
| **C. 解剖定位**（辅助，非诊断） | 肺叶/结构是否准 | **TotalSegmentator** | 目视检查 mask |

**主测模型：CT-CLIP / CT-CHAT**（*Nat Biomed Eng* 2026，PMID 41680439）——目前公开文献里，最贴「3D 胸部 CT 诊断解读」的开源基础模型。

## 2. 实验设计（适合单例自测）

### 2.1 材料

- 1 份完整胸部 CT 系列（DICOM 或 NIfTI，建议去标识）
- 你的盲法读片结论（先写好，再看模型，避免锚定偏倚）
- GPU：建议 ≥16 GB（跑 CT-CHAT）；仅测 TotalSegmentator / Sybil 可更低

### 2.2 流程

```
1. 你先独立写读片结论（金标准）
2. 同一预处理后的体积分别喂给各模型
3. 记录输出，不做提示工程「调到满意」
4. 用统一评分表打分（见下）
5. 再做一次「开放提问」看 CT-CHAT 是否会幻觉
```

### 2.3 评分表（单例也够用）

对每个「临床相关发现」打分（例如：结节、实变、GGO、积液、气胸、淋巴结增大…）：

| 分项 | 定义 | 分值 |
|------|------|------|
| 真阳性 TP | 你认为有，模型也报了 | +1 |
| 假阴性 FN | 你认为有，模型漏了 | 记 1 次漏诊 |
| 假阳性 FP | 你认为无，模型报了 | 记 1 次过诊 |
| 定位 | 侧别/肺叶是否基本正确 | 对/错 |
| 表述可用性 | 是否像可核对的放射描述 | 1–5 |

汇总：`敏感度≈TP/(TP+FN)`，`精确度≈TP/(TP+FP)`（单例仅作定性，不写进论文当正式指标）。

### 2.4 固定提问模板（CT-CHAT，保证可比）

对所有对话式模型只用同一组问题，不要临时改：

1. 请列出本例胸部 CT 的主要异常发现（按重要性排序）。  
2. 肺实质有无结节？若有，给出侧别、大致肺叶、大小估计。  
3. 有无实变、磨玻璃、纤维条索？  
4. 有无胸腔积液或气胸？  
5. 还有哪些需要鉴别但把握不高的发现？

## 3. 参赛模型说明（为何这几个）

### A 组主测：CT-CLIP / CT-CHAT

| 项 | 内容 |
|----|------|
| 文献 | Hamamci et al., *Nat Biomed Eng* 2026 |
| 数据 | CT-RATE：25,692 例非增强 3D 胸部 CT + 报告 |
| 测法 | CT-CLIP → 多异常 zero-shot 标签；CT-CHAT → 问答/草稿报告 |
| 适合比 | 「通读诊断」能力 |
| 注意 | 训练偏非增强；增强期、厚层、截断视野可能变差 |

### B 组（可选）：Sybil

| 项 | 内容 |
|----|------|
| 文献 | Mikhael et al., *J Clin Oncol* 2023 |
| 验证 | NLST / MGH / CGMH；1 年 AUC 0.86–0.94 |
| 测法 | 输出 1–6 年肺癌风险 |
| 适合比 | 筛查风险分层，**不是**「当前有无癌」的诊断器 |
| 注意 | 仅在 LDCT 场景有意义；与 CT-CHAT 发现列表分开看 |

### C 组（质控用）：TotalSegmentator

| 项 | 内容 |
|----|------|
| 文献 | Wasserthal et al., *Radiol Artif Intell* 2023 |
| 测法 | 看肺/气管 mask 是否完整 |
| 用途 | 确认输入体积方向、覆盖范围没问题；不参与「诊断胜负」 |

### 不建议拿来和 CT-CHAT 直接比「胸部诊断」

- **Merlin**（*Nature* 2026）：腹部 CT VLM，任务域不同  
- **通用 ChatGPT/Claude + 几张截图**：不是 3D 体积模型，可比性差，最多当「弱基线」

## 4. 最小操作清单

```bash
# 1) DICOM → NIfTI
dcm2niix -z y -o ./nifti ./dicom_series

# 2) 解剖质控（可选但推荐）
TotalSegmentator -i scan.nii.gz -o seg_out -ta total

# 3) CT-CLIP 多异常 / CT-CHAT 问答
#    按官方 CT-RATE / CT-CLIP / CT-CHAT 仓库说明加载权重与推理
#    输入：同一 NIfTI；输出：标签概率 + 问答文本 → 记入评分表

# 4) 若为 LDCT，再跑 Sybil
#    按官方 Sybil 仓库推理，记录 year1–year6 风险
```

权重与代码以各论文配套公开仓库为准（CT-RATE / CT-CLIP / CT-CHAT、TotalSegmentator、Sybil）。

## 6. 边界（医生自测也建议守住）

- 这是 **n=1 方法学试跑**，不能外推到模型优劣的正式结论  
- 生成式输出可能幻觉：以你读片为准  
- 研究权重通常 **非注册器械**；结果仅用于你个人的模型评估兴趣  
- 若以后要写进论文，至少扩到外部病例集 + 预先注册评分规则

## 8. 你这边只需确认 3 件事即可开跑

1. **影像：** 非增强胸部 CT，还是增强 / LDCT？  
2. **对比目标：** 只要通读（A），还是加上 Sybil 风险（B）？  
3. **环境：** 本地 GPU 型号与显存  

确认后可直接搭 S0 推理脚本，把同一 NIfTI 跑完并填评分表。
